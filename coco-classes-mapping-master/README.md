# COCO to Cityscapes Classes Mapping

This folder contains tools and mappings to seamlessly convert COCO panoptic dataset predictions into Cityscapes classes for Zero-Shot cross-dataset evaluation.

## Files Description

### 1. `bridge_to_cs.py`
This is the core Python script responsible for dynamically bridging the domain gap between COCO's granular 133 panoptic classes and Cityscapes' 19 evaluation classes. It loads the official COCO categories, strips suffixes (e.g., `wall-brick` reduces to `wall`), applies a custom synonym dictionary (e.g., `tree` -> `vegetation`), and iterates over the dense model indices (0-132) to generate a robust mapping.

### 2. `panoptic_coco_categories.json`
This file contains the official list of 133 panoptic COCO categories used as the source of truth for mapping the model's output indices. 
It was downloaded directly from the official COCO dataset repository using the following command:
```bash
wget https://raw.githubusercontent.com/cocodataset/panopticapi/master/panoptic_coco_categories.json -P /content/drive/MyDrive/FundGitHubProject/eomt/data
```

### 3. `coco_to_cs.json`
This is the final, purely numerical mapping file generated by executing `bridge_to_cs.py`. It consists of a dictionary where the keys are the model's dense output indices (0-132) and the values are the corresponding Cityscapes class IDs (0-18). This file acts as an O(1) lookup table that is loaded directly onto the GPU during the evaluation loop to maximize inference speed.
